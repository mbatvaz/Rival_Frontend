# Rival_Frontend

Persian RTL static frontend reference for future ASP.NET Core MVC. See the [Persian setup guide](README_START_HERE_FA.md) to run the preview locally.

Codex uses the [root instructions](AGENTS.md). The [owner gate](docs/PHASE_PLAN.md#current-owner-gate) and [Git workflow](docs/GIT_WORKFLOW.md) govern phase acceptance and publication.

The [preview directory](preview-review/README.md) maintains separate manual mobile, desktop and final review decisions. Preview revisions are tracked independently of phase acceptance.
