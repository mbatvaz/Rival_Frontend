## Coverage limitations

- Some Batch 5/8 `.dc.html` files depend on `/_blob` or Claude Design support scripts and may not render independently. Preserve them as evidence; use the related preview/source artifacts and handoff.
- Several source exports are 390px-only. Desktop layouts are now defined by the owner as purpose-designed compositions derived from the mobile design language and must be reviewed per page.
- No real backend/API implementation was supplied. Mock API shapes are reference contracts, not final backend contracts.
- Missing decorative assets and intentional placeholders remain documented in `ASSET_AUDIT.md`; do not invent replacements.
