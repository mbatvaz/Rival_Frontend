# Frontend fidelity

Read the assigned page spec, [source map](../../../docs/ai/DESIGN_SOURCE_MAP.md), actual source HTML/screenshots and component handoff. Verify route, state, source dimensions and capture scale; null selectors or missing sources remain gaps.

Capture the runtime at matching mobile dimensions, then compare desktop against its actual reference or approved brief. Check layout, hierarchy, copy, typography, spacing, palette, assets/icons, container, responsive behavior and motion. Record at least five concrete source-versus-runtime observations in a [visual report](../../../docs/ai/templates/visual-qa-report.md).

Fix significant mismatches within assigned scope and repeat affected checks until resolved or explicitly recorded as deviations with severity and acceptance status. A pending deviation is not approved. Do not redesign the page or claim pixel fidelity from automated assertions. Output exact source paths, state URLs, screenshots, observations, fixes and remaining limits.
