# گزارش بازبینی دوم فاز دوم

ده اصلاح در نظرهای جدید مالک اجرا شد. این گزارش بر انتخاب‌های نمایشی متفاوت در گزارش قبلی تقدم دارد؛ محدوده همچنان فاز دوم است و پذیرش نهایی با مالک خواهد بود.

| نظر | نتیجه |
|---|---|
| ۱ | هیرو از عرض قبلی ۱۱۵۲ پیکسل، در هر طرف ۲۰٪ عریض‌تر شد؛ حداکثر عرض ۱۶۱۲٫۸ پیکسل است. در نمایشگر کوچک‌تر، فاصلهٔ ۲۴ پیکسل از کناره‌ها حفظ می‌شود. این تغییر فقط دسکتاپ است. |
| ۲ | ناوبری دسکتاپ پس‌زمینهٔ تیره و شعاع گوشهٔ برابر دکمهٔ ورود/پنل دارد. |
| ۳ | ارتفاع نقشه در دسکتاپ با فضای باقی‌مانده تنظیم می‌شود تا انتهای تصاویر سالن و مجموع نقشه، پیوندها و کارت رزرو هم‌تراز شوند؛ کارت رزرو ارتفاع طبیعی خود را دارد. |
| ۴ | نمایشگر نمونه‌کار در دسکتاپ وسط صفحه و در موبایل متصل به پایین است. لمس بومی موبایل، کشیدن موس، غلتک عمودی برای جابه‌جایی تصویر و اسکرول افقی موس/ترک‌پد فعال‌اند. |
| ۵ | خطای بارگیری نمونه‌کار دسکتاپ هم‌عرض و هم‌راستای کارت دعوت رزرو است. |
| ۶ | فهرست قوانین دسکتاپ با فاصلهٔ ۲۴ پیکسل از بالای نمایشگر چسبان می‌ماند و با پایان محتوای قوانین محدود می‌شود. |
| ۷ | شمارش جداگانهٔ اعتبار کد سمت راست حذف شد؛ شمارش ارسال مجدد در مرکز است. |
| ۸ | پنج خانهٔ کد عمودی‌اند: حداکثر عرض ۵۲ و ارتفاع ۶۴ پیکسل؛ در موبایل باریک عرض کاهش می‌یابد. ورود، انتخاب رقم، paste و autocomplete حفظ شدند. |
| ۹ | در حالت انقضا هم فقط گزینهٔ ارسال مجدد در مرکز دیده می‌شود. انقضای واقعی کد همچنان هنگام بررسی ورودی اعمال می‌شود. |
| ۱۰ | ورود با رمز دیگر پنجرهٔ شناور ندارد؛ یک نمای کامل صفحهٔ ورود با شماره و رمز در login/?method=password است. گزینهٔ دوم به «ورود با ارسال پیامک» تغییر می‌کند. بازخوانی، عقب/جلوی مرورگر و return داخلی پشتیبانی می‌شوند. |

## پیاده‌سازی و تصمیم‌ها

- فایل‌های اصلی: home-desktop.css، public.css، sheets.css، portfolio-states.css، rules.css، otp.css، auth.css، Login.njk و _PortfolioViewer.njk.
- gallery-rail.js از طریق feature registry بارگذاری می‌شود؛ ریل لمسی بومی می‌ماند و تنها تعاملات موس به آن افزوده شده‌اند.
- auth-methods.js و auth-view.js بازنویسی شدند؛ جابه‌جایی فرم و نسخهٔ موقت پس‌زمینهٔ پنجرهٔ رمز حذف شد. نمای مستقل رمز همان Auth layout را استفاده می‌کند.
- DEC-037 تا DEC-040 و briefهای دسکتاپ ثبت شدند. دستور مستقیم جدید مالک، برای نمایشگر نمونه‌کار دسکتاپ استثنای صریح قاعدهٔ قدیمی برگهٔ پایین است؛ سایر برگه‌ها تغییر موقعیت نداده‌اند.
- قفل مشترک روش‌های ورود، شمارش تلاش، اعتبار ۱۲۰ ثانیه‌ای کد و مکث ۶۰ ثانیه‌ای ارسال مجدد تغییر نکرده‌اند.

- npm test: ۵۶ موفق.
- npm run test:subpath: ۵۶ موفق؛ خروجی مسیر اصلی پس از پایان بازیابی شد.
- آزمون چیدمان و لمس در ۳۲۰/۳۹۰/۷۶۸/۱۲۸۰ و حالت‌های خطا/بارگیری/ورود؛ کنترل خاص بازبینی در ۴۱۷/۴۷۱/۱۹۲۰.
- آزمون موس واقعی و ژست لمسی مرورگر، مرکز/پایین بودن نمایشگر، بازگردانی فوکوس و اسکرول، چسبندگی قوانین، انقضا/ارسال مجدد/قفل، نمای رمز و تاریخچه موفق بودند.
