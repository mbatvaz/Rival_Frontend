# گزارش اصلاحات بازبینی فاز دوم

اصلاحات مطابق ۲۰ نظر مالک و ۹ تصویر ارسالی اجرا شد. دستورهای جدید مالک دربارهٔ دسکتاپ، روش‌های ورود و پیوندهای نمونه بر تصمیم‌های نمایشی قبلی تقدم دارند. این نسخه آمادهٔ بازبینی مالک است؛ فاز سوم آغاز نشده است.

## اصلاحات مشترک و فایل‌ها

- زیرخط تمام پیوندها حذف شد و نوار اسکرول، با حفظ امکان اسکرول، پنهان است.
- ورود نرم صفحات و برگه‌ها، به‌علاوهٔ native document view transition در مرورگر پشتیبان؛ reduced-motion همه را متوقف می‌کند.
- برگهٔ جزئیات/رمز/خروج، زمینه را قابل‌مشاهده و inert نگه می‌دارد؛ دام فوکوس، Escape، برگهٔ تودرتو و بازگردانی اسکرول/فوکوس برقرارند. برای حفظ هندسهٔ پس‌زمینه تنها offset اسکرول در متغیر CSS زمان اجرا ثبت می‌شود.
- اجزای قابل‌استفادهٔ مجدد: materials.css، otp.css و components/otp.js، _Otp.njk، _PolicyWindow.njk، _PortfolioFeedback.njk، auth-notices.css و motion.css. مسیر مهاجرت MVC و مرز data adapter حفظ شده‌اند.
- قالب‌های Public/Home، Portfolio، Rules، Auth/Account و HeaderPublic، fixtureها و briefهای دسکتاپ اصلاح شدند. فهرست تغییرات در Git موجود است.

## آزمون و تصاویر

- npm run build: موفق؛ ۶ قالب محصول، ۶۷ جای‌نگهدار برچسب‌دار و ۷۵ خروجی HTML.
- npm run lint: موفق؛ structure، ESLint و Stylelint.
- npm test: ۵۰ موفق در مسیر اصلی.
- npm run test:subpath: ۵۰ موفق در /rival-demo/؛ خروجی مسیر اصلی پس از آزمون بازیابی شد.
- پس از افزودن محافظ paste روی شمارهٔ read-only، ۱۳ سناریوی مرتبط ورود/بازبینی در هر دو مسیر دوباره موفق بودند.
- آزمون‌های واکنش‌گرا و لمس: ۳۲۰، ۳۹۰، ۷۶۸ و ۱۲۸۰؛ کنترل اختصاصی نظرهای مالک در ۴۱۷، ۴۷۱ و ۱۹۲۰.
- axe در ۳۹۰/۷۶۸/۱۲۸۰ و حالت‌های خطا/بارگیری/برگه: بدون خطای WCAG A/AA گزارش‌شده. آزمون‌های صفحه‌کلید، مسیر و دارایی‌های محلی موفق بودند.
- ۵۹ تصویر در هر مسیر: tests/screens/phase02-revision/root/ و tests/screens/phase02-revision/subpath/.
- بازبینی تصویری مستقیم: خانهٔ موبایل/دسکتاپ، کد پیامکی و خطای آن، ورود با رمز روی زمینه، خطای نام، قوانین، نمونه‌کار خالی و نمایشگر جزئیات. تصاویر مرجع و design-export بدون تغییر ماندند.

## محتوای قابل‌تکمیل در توسعه

شمارهٔ تماس طبق دستور مالک ثبت شده است. پیوندهای اجتماعی/نقشه با مجوز مالک غیرواقعی و با عنوان «نمونه» هستند؛ برای جایگزینی، links در src/MockData/public/home.json را تغییر دهید. شماره در home.json و rules.json است. مقصدهای .example حساب یا موقعیت واقعی را معرفی نمی‌کنند.

منبع فقط برای یک نمونه‌کار گالری سه‌عکسی و توضیح کامل دارد؛ برای دیگر موارد فقط تصاویر و اطلاعات موجود استفاده شده‌اند (GAP-20). Passkey و SMS همچنان آزمایشی‌اند و نیازمند اتصال backend در توسعه هستند؛ این بازبینی تغییری در قواعد قفل مشترک، اعتبار کد یا شمارش تلاش‌ها نداده است.

پذیرش بصری نهایی فاز دوم با مالک است. مسیر پیش‌نمایش محلی همان http://localhost:4173/ است.
