## انیمیشن و سازگاری

مرجع جدید حرکت، نظر مستقیم مالک است و در موارد مربوط جایگزین پاپ/بالاآمدن منبع می‌شود. [حرکت انتخاب‌ها](../src/wwwroot/js/features/booking/selection-motion.js) از Web Animations بومی، duration-base=240ms، ease-standard و نصف duration-fast=70ms برای تأخیر استفاده می‌کند. خروج ماه: opacity ۱ به ۰ و translateX از صفر به space-3؛ ورود جهت مخالف است. هر هفت خانه یک تأخیر مشترک دارند؛ تأخیرها تصادفی نیستند.

هر عنصر انیمیشن قبلی خود را لغو می‌کند؛ شماره نسخه شبکه جلوی جایگزینی نتیجه قدیمی را می‌گیرد. تغییر زنده reduced motion انیمیشن‌ها را لغو و وضعیت نهایی را نگه می‌دارد. نبود animate نیز نمایش مستقیم را حفظ می‌کند. بستن/بازکردن برگه، تغییر انتخاب و صفحه‌کلید در آزمون‌ها پوشش دارند. جابه‌جایی گالری از اسکرول نرم بومی استفاده می‌کند؛ بدون حرکت، همان انتخاب نهایی باقی است.

بودجه این تغییر: خواندن token فقط هنگام تعامل، بدون حلقه اندازه‌گیری در هر فریم و بدون handler جدید scroll سنگین؛ حرکت ماه و ورود ساعت با transform/opacity. انتقال سایه/رنگ انتخاب‌ها کوتاه و محدود به همان کنترل است. هیچ dependency اضافه نشد. زمان‌بندی/ترتیب از API انیمیشن مرورگر بررسی شد؛ FPS و زمان paint اندازه‌گیری نشده و ادعای امتیاز عملکرد نداریم.

[آزمون چرخ‌فلک](../tests/phase02/carousel-motion.spec.mjs) با حذف کنترل توقف و تکرار مراحل هماهنگ شد. رگرسیون موجود axe، مسیرها، خطاهای کنسول، فرم‌ها، صفحه‌کلید، وضعیت خالی/خطا/انقضا و ذخیره مستقل بازبینی را بررسی می‌کند.

نتایج واقعی فرمان‌ها:

- build و lint: موفق، exit 0؛ ساختار، JavaScript، CSS و پیوندهای مستندات بررسی شدند.
- `npm.cmd test -- --workers=2`: تمام ۱۱۰ آزمون موجود در زمان اجرا موفق، exit 0؛ شامل axe و صفحه‌کلید در ۳۹۰/۷۶۸/۱۲۸۰.
- `npm.cmd run test:subpath`: تمام ۱۱۰ آزمون موفق، exit 0؛ خروجی ریشه پس از آن بازسازی شد.
- یک اجرای قبلی ریشه ۱۰۹/۱۱۰ داشت: کلیک ثبت درخواست هنگام ناپایداری چیدمان متوقف شد. مسیر پیشنهادی در هشت تکرار مستقل عبور کرد و اجرای کامل دو-worker بالا نیز عبور کرد؛ علت قطعی رخداد منفرد ثابت نشده است.
- پس از افزودن [آزمون حرکت نرم گالری](../tests/phase02/gallery-settle.spec.mjs)، آزمون گالری به‌همراه رگرسیون نمایشگر و API در ریشه ۱۱/۱۱ و همین‌ها همراه بازخورد مالک در زیرمسیر ۱۵/۱۵ موفق شدند، exit 0. این آزمون تغییر موقعیت در چند فریم و خطای مرکز کمتر از ۲ پیکسل را بررسی می‌کند. دو سر ریل نیز فاصله لازم برای مرکزشدن تصویر اول/آخر دارند.
- مسیر استقرار دوباره `/` است؛ هیچ dependency، انتشار یا عملیات واقعی اضافه نشده است. بازآزمایی فیزیکی موبایل انجام نشده است.
- نمایش اولیه ساعت‌ها نیز مانند تعویض روز، fade ترتیبی دارد. پس از این تکمیل، رگرسیون مستقیم رزرو و بازخورد مالک ۹/۹ موفق شد؛ lint نهایی و بررسی whitespace نیز موفق بودند.

درباره عبارت نوار ناوبری پایین، سؤال روشن‌سازی برای مالک باز است؛ وضعیت قبلی آن تا پاسخ تغییر نمی‌کند. این گزارش پذیرش نهایی محصول یا اجازه استقرار نیست.
