# BK-R01 — درخواست خدمت چندبخشی

نسخهٔ دوم طرح دسکتاپ · تأیید مالک در ۲۰ آبان ۱۴۰۵

پنل اصلی معرفی خدمت و فهرست اجزای پکیج را با تصویرهای بندانگشتی هم‌تراز نشان می‌دهد. ستون سمت چپ شرایط هماهنگی و اقدام «ثبت درخواست» را کنار هم قرار می‌دهد. انتخاب تاریخ، آرایشگر و متن آزاد در این مسیر وجود ندارد.
