# STATE-07 — اختلال سرویس بیرونی

نسخهٔ دوم طرح دسکتاپ · تأیید مالک در ۲۰ آبان ۱۴۰۵

نمای درگاه خطا را داخل پنل پرداخت و کنار تلاش دوباره نشان می‌دهد. خطای پیامک کنار رسید و خطای نقشه یا ارسال کد در همان کارت تماس یا فرم ورود قرار می‌گیرد. این حالت‌ها مسیر مرور کاربر را حفظ می‌کنند.
