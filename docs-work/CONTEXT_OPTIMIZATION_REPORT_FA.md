# گزارش بهینه‌سازی زمینه و ناوبری Rival

تاریخ: ۲۰۲۶-۱۱-۱۶. مالک پس از ممیزی و پژوهش، ایجاد ابزارها و ادامهٔ مراحل باقی‌مانده بدون توقف تأیید را مجاز کرد. این مجوز مربوط به زیرساخت عامل است؛ فاز ۴، تغییر محصول یا انتشار Git را مجاز نمی‌کند.

## نتیجه و ورودی‌ها

[نمایهٔ کوتاه](../docs/ai/PROJECT_INDEX.md) مسیر شروع است؛ [راهنمای گراف](../docs/ai/PROJECT_GRAPH.md) روش استخراج و محدودیت‌ها را توضیح می‌دهد. [گراف ماشینی](../docs/ai/project-graph.json) برای پرس‌وجوی ابزار است و نباید کامل وارد زمینهٔ گفتگو شود. مرجع اختیار همچنان قرارداد و تصمیم مالک است.

پیش از تغییر، دستور ریشه ۶٬۳۲۷ بایت بود و خواندن پنج سند عمومی با مجموع ۷۸٬۴۸۶ بایت را درخواست می‌کرد. این حجم الزام بالقوهٔ خواندن است، نه مصرف توکن اندازه‌گیری‌شده. ده مهارت قبلی مجموعاً ۱۶٬۶۱۳ بایت بودند؛ بدنهٔ همهٔ مهارت‌ها خودکار بارگذاری نمی‌شود. هزینهٔ واقعی به انتخاب مهارت و منابع خوانده‌شده وابسته است.

## منابع بیرونی ارزیابی‌شده

- [rdilruba/codebase-map](https://github.com/rdilruba/codebase-map): روش‌های UPDATE/CHECK و برچسب قطعیت مفید؛ بدنهٔ ۸۵۶سطری و خواندن کامل فایل‌ها برای نصب مستقیم مناسب این هدف نیست. مجوز MIT بررسی شد؛ کدی کپی نشد.
- [fadhlirahim/codebase-map](https://github.com/fadhlirahim/codebase-map): نمایشگر HTML مستقل و اسکریپت Node؛ استخراج پیش‌فرض آن قالب njk و روابط واقعی Rival را پوشش نمی‌دهد. بازسازی، به‌روزرسانی افزایشی معنایی نیست. مجوز MIT بررسی شد؛ نمایشگر به آینده موکول شد.
- [Aider Repo Map](https://aider.chat/docs/repomap.html): مرجع انتخاب زمینهٔ مرتبط و محدود. پیاده‌سازی Python/Tree-sitter/کش آن منتقل نشد؛ هیچ کدی کپی یا نصب نشد.
- [Dependency Cruiser](https://github.com/sverweij/dependency-cruiser): تحلیل JS مفید، ولی با وابستگی‌های اضافی و پوشش ناقص قالب/طراحی. نسخهٔ main بررسی‌شده شرط Node جدیدتری از حداقل قرارداد پروژه دارد؛ ضرورت نصب اثبات نشد. مجوز MIT بررسی شد.
- [راهنمای رسمی مهارت‌ها](https://learn.chatgpt.com/docs/build-skills) و Skill Creator داخلی برای ساخت مهارت کوتاه و بارگذاری مشروط استفاده شدند. [مخزن قدیمی skills](https://github.com/openai/skills) رسماً منسوخ است؛ نسخهٔ دیگری نصب نشد.
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): وجود مخزن بررسی شد؛ نیاز ضروری به توصیهٔ طراحی عمومی اثبات نشد، بنابراین بررسی عمیق یا نصب انجام نشد.

SHA ثابت منابع بیرونی بازیابی نشد؛ ارزیابی مبتنی بر محتوای بازیابی‌شده از main است. این بررسی تضمین امنیت همهٔ فایل‌های آن مخازن نیست. هیچ کد بیرونی اجرا یا وارد مخزن نشد و هیچ وابستگی یا تنظیم سراسری تغییر نکرد.

## استخراج و پوشش

گراف، صفحه/مسیر، قالب/partial، ویژگی/ماژول JS، سبک، متغیر/توکن، دادهٔ ساختگی، آزمون، مرجع طراحی، brief، فاز و مقصد برنامه‌ریزی‌شدهٔ Razor را متصل می‌کند. مسیرها نسبت به مخزنند؛ رابطه‌ها شاهد و وضعیت CONFIRMED یا INFERRED دارند. موارد نامعلوم به‌صورت شکاف با UNKNOWN ثبت می‌شوند.

تحلیل قالب با AST نانجاکس، JS با AST ابزار موجود ESLint و CSS با AST ابزار موجود Stylelint انجام می‌شود. هیچ parser جدیدی نصب نشد. کلاس‌ها و data-rv از بخش‌های لفظی استخراج می‌شوند؛ کلاس‌های پویا و برخی dispatchهای زمان اجرا ناقص می‌مانند. رابطهٔ import تأییدشده فقط وجود اعلان را ثابت می‌کند، نه اجرای آن شاخه.

برای تمام ۷۳ زمینهٔ رجیستری، ارتباط مسیر و نامزدهای مانیفست بررسی می‌شود؛ ۲۱ مورد قالب و پذیرش دارند و ۵۲ مورد جای‌نگهدارند. مانیفست برای ۵۸ مورد HTML ترجیحی ندارد و selector هر ۷۳ مورد تهی است. این شکاف‌ها پنهان یا خودکار حل نشدند. تصاویر و HTML مرجع به‌طور بصری در این کار ارزیابی نشدند.

نگاشت CSS مبتنی بر اشتراک کلاس، محافظه‌کارانه و احتمالی است؛ شرط‌های قالب ممکن است مصرف‌کنندگان اضافی نشان دهند. ارجاع آزمون به مسیر/شناسه، اثبات پوشش حالت یا قبولی آزمون نیست. نگاشت دادهٔ پویا و تمام کلاس‌های ایجادشده در اجرا کامل نیست. مقصد MVC صرفاً قرارداد برنامه‌ریزی‌شده است؛ بک‌اند در این مخزن موجود نیست.

برای کاهش نامزدهای شرطی، صفحات دارای قالب با مدل و helperهای فعلی فقط در حافظه رندر می‌شوند؛ هیچ خروجی محصول یا دارایی نوشته نمی‌شود. renderedPages کامپوننت‌های مشاهده‌شده در رندر ایستای پیش‌فرض را از possiblePages ساختاری جدا می‌کند. ماژول‌های شرطی رزرو با helper موجود review-scope محدود می‌شوند. URL دارایی‌های محلی در HTML رندرشده و CSS نیز به فایل منبع وصل و از نظر وجود مسیر کنترل می‌شود؛ srcset یا URL پویا پوشش کامل ندارند. این کار اجرای مرورگر یا اثبات تمام حالت‌های تعاملی نیست.

مرجع توکن، JSON اصلی است؛ CSS تولیدشده و استفاده‌های var قابل بازیابی‌اند. توکن‌های breakpoint/container/z-index جدیدی ساخته نشد. منابع طراحیِ ارجاع‌شده از نظر وجود مسیر بررسی می‌شوند؛ محتوای باینری/HTML آن‌ها در هر CHECK هش یا تفسیر نمی‌شود.

## نگهداری و کنترل تازگی

```text
npm run map:build
npm run map:update
npm run map:check
npm run map:query -- BK-REQ01
npm run map:query -- StatePage
npm run map:query -- --accent-500
npm run map:query -- feature:booking
node --test tools/tests/project-map.test.mjs
```

BUILD همهٔ ورودی‌های محدوده را تحلیل می‌کند. UPDATE همان موجودی محدود را هش می‌کند، واقعیت‌های فایل‌های بدون تغییر را بازاستفاده و اتصال‌های بین‌فایلی را بازسازی می‌کند؛ ادعای حذف همهٔ خواندن‌ها یا افزایشی‌بودن تمام joinها وجود ندارد. تغییر extractor کش تحلیل را باطل می‌کند. فایل حذف‌شده/جدید و تغییر ثبت‌نشده نیز شناسایی می‌شوند.

CHECK و QUERY نمی‌نویسند؛ QUERY وضعیت تازگی را گزارش می‌کند. CHECK خرابی مسیر، شواهد، تکرار مسیر/شناسه، چرخه‌های وابستگی و تغییر خروجی راهنما را بررسی می‌کند. آرشیو، node_modules، خروجی محصول، کش و تصاویر آزمون در پیمایش نیستند. آزمون ابزار در fixture موقت محدود اجرا و پاک‌سازی می‌شود.

## تغییر مسیریابی و مهارت‌ها

دستور ریشه الزام خواندن همیشگی پنج سند را به انتخاب سند متناسب با کار تبدیل کرد. چارچوب مجاز، RTL، مرز داده، فازها، استثناهای تأییدشده، پذیرش دسکتاپ و کیفیت UI حفظ شدند. گراف و خلاصه جای قرارداد را نمی‌گیرند.

هر ده مهارت قبلی حفظ شد؛ فقط rival-context اضافه شد. QA عمومی مالک بررسی‌های مشترک است؛ fidelity، responsive، motion و debugging شواهد تخصصی را اضافه می‌کنند. منابع قبلاً خوانده‌شده و نتایج معتبر برای همان revision/scope دوباره تولید نمی‌شوند؛ تغییر مؤثر نیاز به بازبینی را بازمی‌گرداند. دروازه‌های کامل فاز تضعیف نشدند.

توضیح قدیمی ذخیرهٔ تأییدها اصلاح شد. سه نام مبدأ ناموجود در نقشهٔ مهاجرت، تاریخی/برنامه‌ریزی‌شده برچسب خوردند و ورودی فعلی معرفی شد. منع مطلق قدیمی اسکرول در پرامپت فاز ۳ در سجل تعارض‌ها ثبت شد؛ بستهٔ فاز تغییر نکرد.

## اعتبارسنجی نهایی و سنجش

- شش آزمون ابزار با Node test runner گذشت: تشخیص parser در برابر comment/متغیر پویا، ناوبری دوطرفه، ننوشتن CHECK/QUERY، قطعیت خروجی و بازاستفادهٔ facts، تغییر/افزودن/حذف فایل، منابع مفقود، خروجی دست‌کاری‌شده، تغییر extractor، مسیر ناامن، تکرار و چرخه. تغییر fixture نیز مصرف کامپوننت در رندر حافظه را باطل و بازسازی می‌کند.
- شش سناریوی واقعی مخزن گذشت: BK-REQ01 و طراحی اصلی، مصرف‌کنندگان StatePage، تعریف و مصرف accent-500، loader رفتار booking، آزمون request-results و مقصد برنامه‌ریزی‌شدهٔ Layout برای MVC.
- برای BK-REQ01، قالب StatePage و ماژول result پیدا شد و ماژول زمان که به نوع پیش‌فرض نتیجه مربوط نیست از مسیر انتخابی کنار گذاشته شد. پنج صفحه در رندر پیش‌فرض از StatePage استفاده می‌کنند؛ مصرف‌کنندگان ساختاریِ احتمالی جدا هستند.
- در اجرای واقعی، بایت‌ها و mtime هر سه خروجی پس از CHECK/QUERY ثابت ماند. UPDATE بدون تغییر، صفر فایل را تحلیل و facts هر ۴۰۴ ورودی را بازاستفاده کرد. خروجی BUILD بعدی با UPDATE از نظر بایت یکسان بود.
- گراف نهایی شامل ۱٬۶۳۹ گره، ۵٬۰۲۶ رابطه و ۱۶۶ شکاف ثبت‌شده است؛ ۲۱ صفحه در حافظه رندر شدند. CHECK مسیرها/تازگی بدون خطا گذشت. شکاف‌های صریح به معنی کامل‌بودن پوشش نیستند.
- اجرای نهایی lint ساختار، JavaScript، CSS و لینک/ساختار مستندات گذشت: ۶۲ سند نگهداری‌شده، ۱٬۶۵۶ پیوند محلی و ۱۱ ورودی مهارت بررسی شد. diff whitespace نیز بدون خطا بود؛ diff مسیرهای محصول، دادهٔ تأییدها، منابع طراحی/اصلی، بسته‌های فاز و lockfile خالی است. شاخه master باقی ماند؛ تغییرات فقط محلی و ثبت‌نشده هستند.
- نمودارهای Mermaid کوچک و از نظر متن و مراجع بررسی شدند؛ موتور مستقل رندر Mermaid اجرا نشد. هیچ ادعای تأیید بصری نمودارها یا صفحات محصول ارائه نمی‌شود. مجموعهٔ مرورگر، build محصول و subpath اجرا نشدند، چون تغییر فقط زیرساخت/مستندات است.

اندازه‌گیری نمونهٔ راه‌یابی: دستور ریشه پس از تغییر ۶٬۱۵۸ بایت، نمایه ۲٬۷۶۱ بایت و خروجی محدود پرس‌وجوی BK-REQ01 حدود ۱۵٬۴۶۵ بایت بود. این‌ها بایت متن‌اند، نه توکن. مقایسهٔ الزام قبلی ۷۸٬۴۸۶ بایت با نمایه/پرس‌وجو فقط جانشین حجم راه‌یابی است؛ خواندن منابع لازم برای انجام کار را حذف نمی‌کند و benchmark کنترل‌شدهٔ قبل/بعد یا درصد صرفه‌جویی نیست. هش‌کردن ورودی‌ها داخل ابزار نیز با واردکردن متن آن‌ها به زمینهٔ مدل تفاوت دارد. زمان/توکن واقعی جلسات بعدی هنوز اندازه‌گیری نشده است.

## وضعیت توصیه‌ها و محدودیت‌ها

- پیاده‌سازی‌شده: گراف، پرس‌وجوی دوطرفه، تازگی، نمایه، مسیریابی و مهارت ناوبری؛ بررسی‌های واقعی در بخش اعتبارسنجی ثبت می‌شوند.
- نیازمند تأیید بیشتر: تطابق بصری، تمام وابستگی‌های پویا، پوشش اجرایی کامل آزمون‌ها و بهبود زمان/توکن در گفتگوهای آینده.
- به‌تعویق‌افتاده: نمایشگر تعاملی و Dependency Cruiser؛ نیاز آن‌ها اثبات نشده است.
- ردشده برای این دامنه: نصب انبوه مهارت‌ها، Aider به‌عنوان runtime، Design System عمومی جایگزین، embedding/پایگاه داده/سرویس خارجی.
- نامعلوم: فناوری واقعی بک‌اند نهایی، انتخاب دقیق منابعی که در مانیفست تهی‌اند و پرسش‌های محصولی حل‌نشده؛ هیچ قاعدهٔ محصولی برای پرکردن این خلأها ساخته نشد.

بهبود بعدی پیشنهادی، ثبت حجم فایل‌های واقعاً خوانده‌شده و تعداد فراخوانی ابزار در چند کار مشابه در جلسات آینده است. تنها پس از این سنجش می‌توان دربارهٔ صرفه‌جویی عملی نتیجه گرفت. اگر یک رابطهٔ پویا مرتب مانع ناوبری شد، extractor همان رابطه با شاهد و آزمون اضافه شود؛ نصب ابزار یا ساخت مستندات موازی، پیش‌فرض نگهداری نیست.

مسیریابی مستقیم یک کامنت تصویر آرایشگر ۴۷۰ بایت برگرداند. میانهٔ سه اجرای فرایند Node در این دستگاه ۹۵ میلی‌ثانیه بود و میانهٔ جست‌وجوی کامل CUS-08 حدود ۱٫۳۸ ثانیه. بازپخش متن سه پیام واقعی دارای کامنت، برای هر پنج هدف در مجموع مسیر تولید کرد. این اندازه‌ها هزینهٔ محلی راه‌یابی و حجم خروجی ابزارند. تغییر توکن کل درخواست، زمان پاسخ سرتاسری و مصرف سهمیه با اجرای کارهای هم‌سطح بعدی قابل اندازه‌گیری است.

اجرای فشردهٔ Playwright خطای دسترسی Chromium به پیش‌نمایش را با یک پیام گزارش کرد و جزئیات را در فایل محلی نگه داشت. هر هفت آزمون اعلان‌ها در مسیر ریشه و `/rival-demo/` پاس شدند. هر ۹ آزمون ابزار و گراف، lint و بررسی تازگی گراف پاس شدند. تأیید هوک در برنامه و اندازه‌گیری درخواست‌های واقعی پس از تغییر باز هستند.

## حذف مسیرهای موازی

مقایسه با Git نشان داد راهنمای شروع قبلی هنوز یک پیش‌پرواز تکراری و فرمان‌های قدیمی آزمون را معرفی می‌کرد. ۲۶ سند دستورالعمل قدیمی با مجموع ۵۶٬۶۰۸ بایت و snapshot قدیمی ممیزی با ۳۸۸٬۸۳۳ بایت از درخت فعال حذف شدند. مجموع اندازهٔ ۹ README فاز از ۱۷٬۱۰۲ به ۵٬۴۶۸ بایت رسید. شرط‌های پذیرش اختصاصی و پیوند شواهد در همان READMEها باقی ماندند.

[AGENTS](../AGENTS.md) ورودی پروژه است. `task:context` شواهد صفحه یا فاز را به‌صورت محلی جمع می‌کند. `npm test` و فرمان آزمون هدفمند VS Code همان `qa:affected` را اجرا می‌کنند. ابزار، خروجی کامل را روی دیسک نگه می‌دارد. پذیرش کامل هر فاز از حالت صریح `--full` عبور می‌کند. این اندازه‌گیری حجم فایل‌هاست. مقایسهٔ مصرف توکن به اجرای درخواست هم‌شرایط در گفت‌وگوی تازه نیاز دارد.

برای تغییر ظاهری عکس آرایشگر، مشترک بودن فایل باعث اجرای ۳۱ آزمون شده بود. مسیر [بررسی ظاهری](../docs/ai/PROMPT_ROUTING.md#local-qa-for-all-phases) اکنون Stylelint فایل، یک ساخت و در صورت نیاز بررسی مستقیم مرورگر را اجرا می‌کند. بازآزمایی با دو عرض ۳۹۰ و ۸۷۵، ۲۳٫۲ ثانیه طول کشید. اجرای قبلی با ۳۱ آزمون ۷۴٫۸ ثانیه و اجرای Stylelint و ساخت با دامنهٔ قدیمی ۱۸٫۲ ثانیه طول کشیده بود. هر دو بررسی مرورگر پاس شدند و هش فایل محصول یکسان بود. اجرای کامل هم اکنون به انتخاب صریح `--full` نیاز دارد و فهرست آزمون فقط در حالت `--plan` شمرده می‌شود.
