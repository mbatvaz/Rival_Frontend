# راه‌اندازی Rival

دستورها را از ریشهٔ مخزن و در PowerShell اجرا کنید. نصب وابستگی و Chromium فقط برای محیطی لازم است که آن‌ها را ندارد.

```powershell
npm.cmd ci
npm.cmd run install:browsers
npm.cmd run dev -- --host 127.0.0.1 --port 8183
```

پس از ساخت، [فهرست پیش‌نمایش](http://localhost:8183/_preview/) در مرورگر باز می‌شود. اگر پورت در دسترس نبود، `--port` را تغییر دهید. تغییرات را در [سورس](src/) انجام دهید. ساخت بعدی خروجی `dist/` را جایگزین می‌کند.

## کار با Codex

درخواست را در همین مخزن با شمارهٔ صفحه، مسیر یا کامنت مرورگر ارسال کنید. Codex از [دستورهای ریشه](AGENTS.md) استفاده می‌کند. برای صفحه یا فاز نامشخص، `task:context` مسیرها و وضعیت را محلی پیدا می‌کند. [راهنمای مسیریابی و آزمون هدفمند](docs/ai/PROMPT_ROUTING.md) · [وضعیت پذیرش فاز](docs/PHASE_PLAN.md#current-owner-gate)

## انتشار و انتقال

پس از مجوز انتشار، محتوای `dist/` را مستقیماً در Document Root قرار دهید. برای نصب در زیرپوشه، پیش از ساخت مقدار `basePath` را در [تنظیمات سایت](src/site-config.json) تعیین کنید. cPanel فایل‌های استاتیک را سرو می‌کند. احراز هویت، رزرو و پرداخت در این فرانت‌اند شبیه‌سازی می‌شوند.
