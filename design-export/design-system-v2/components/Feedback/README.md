# Feedback

اطلاع درون صفحه و پیام کوتاه، هر دو تخت و تک‌رنگ — بدون شیشه و بدون گرادیان.

- `.rv-notice.is-TONE`: زمینه تخت `*-bg`، لبه ۱px `*-line` و آیکون ساده `<i class="ri">` به رنگ `*-fg`؛ با `.rv-notice__t` و `.rv-notice__d`. چه شد، چه اثری دارد، قدم بعد.
- `.rv-toast`: سفید جامد با `shadow-md` و دایره تک‌رنگ `.rv-ic.is-TONE`؛ از بالا با `rv-toast-in`؛ یک اقدام (بستن، جزئیات، تلاش دوباره، بازگردانی).
- رنگ فقط در زمینه، لبه و آیکون است؛ سایه همیشه جوهری.
- **جای Toast:** بالای صفحه داخل `.b4-toastwrap` (فاصله `space-3` از بالا و `space-4` از کناره‌ها)؛ نتیجه عمل‌های سبک Toast است، نه صفحه جدا.
- مهلت‌ها با ساعت واقعی گفته می‌شوند («تا امروز ساعت ۱۷:۲۰»)، نه با عدد ثابت ساعت (D10-60).
