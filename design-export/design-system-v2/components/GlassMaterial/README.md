# GlassMaterial

مواد سیستم روی عکس واقعی سالن:

- `.rv-glass` — شیشه شفاف (۵۶٪، blur 22، saturate 180٪) برای کارت، فهرست، تقویم.
- `.rv-glass-strong` — شیشه پررنگ (۷۸٪، blur 36) برای برگه، دیالوگ، منو، نوار پایین و هر چیزی روی عکس.
- `.rv-notice` و `.rv-toast` شیشه‌ای نیستند: تخت و تک‌رنگ.
- `.rv-smoke` — صفحه دودی برای متن سفید روی عکس.
- سفید جامد برای فیلد، روز و زمان. سایه همیشه جوهری؛ شیشه روی شیشه نمی‌نشیند.
