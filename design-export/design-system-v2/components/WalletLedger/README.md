# WalletLedger

کیف پول و دفتر اعتبار تغییرناپذیر (BR-WAL).

- کارت موجودی: کاشی سبز، «اعتبار قابل استفاده» با `numeral-xl`، تگ «در نگه‌داشت» و نوار سبز سهم آزاد.
- سطرها: افزایش اعتبار و برگشت هزینه (`accent`، مبلغ مثبت سبز)، در نگه‌داشت (`accent` خط‌چین)، کسر برای رزرو (`neutral`)، اصلاح مدیر (`plum`)، برگشت سطر (`rose`، با ارجاع).
- دفتر ویرایش نمی‌شود؛ هر اصلاح یک سطر تازه با دلیل و نام مدیر است.
