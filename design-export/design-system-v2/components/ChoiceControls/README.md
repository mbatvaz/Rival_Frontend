# ChoiceControls

گزینه‌ها، تیک، رادیو و سوییچ. همه انتخاب‌ها جوهری‌اند.

- `.rv-option` ردیف سفید تخت با لبه مویی و کاشی تخت (بدون گرادیان)؛ انتخاب‌شده `aria-checked="true"` با حلقه جوهری ۲px.
- `.rv-check` (گوشه ۷px) و `.rv-radio` روی input بومی؛ `.rv-switch` برای تنظیمات روشن/خاموش.
- روش پرداخت گزینه نیست (BR-PAY-02): اعتبار خودکار اول مصرف می‌شود و فقط مانده به درگاه می‌رود. نمونه این کارت روش ورود است.
